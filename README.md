# lrac-skills

本项目维护个人化的skills，目的是让agent能够固定真实科研中的经验

## Fast Start
使用如下命令来进行部署:
```
npx skills add lirnut/lrac-skills
```

使用如下明来来进行更新：
```
npx skills update lirnut/lrac-skills 
```


## 目录结构

```text
lrac-skills/
├── README.md
├── .gitignore
└── skills/
    └── academic-slides/
        ├── SKILL.md
        ├── references/
        ├── scripts/

```
